## EDA에서 전략으로

### Q1. 수명 분포와 짧은 수명 셀

| 배치 | 중앙값 | 500 미만 | 1,000 초과 |
|---|---:|---:|---:|
| B1 | 858.5 | 0.0% | 21.7% |
| B2 | 472.0 | 71.8% | 7.7% |
| B3 | 1,005.5 | 0.0% | 52.3% |

분포는 레이블 보유 셀 전체 기준이다. B1에는 B2의 주요 단수명 구간이 없으므로 B2 전체 MAPE뿐 아니라 짧은 수명·실험집단별 오류를 함께 본다. 배치별 가장 짧은 셀은 같은 정책의 동료 셀과 비교하며, 짧다는 이유로 테스트 셀을 삭제하지 않았다.

B1에서 550사이클 미만은 1셀뿐이어서 장단수명 분류 경계를 학습하기 어렵다. 연속 수명을 예측해 점검 우선순위를 비교하는 **회귀**를 선택했다.

### Q2. 열화 속도와 knee

종료 근접 셀에서 수명 하위·상위 1/3을 비교했다. 초기 10→100사이클 용량 변화의 중앙값은 절댓값 약 0.02 mAh/사이클 이하로 작고, 배치마다 순서가 달랐다. 이는 통계적 차이가 없음을 입증하는 검정 결과가 아니다. 마지막 20% 구간에서는 하위 1/3의 감소 속도가 상위 1/3 대비 B1 1.47배, B2 1.80배, B3 1.60배였다.

탐색 knee 중앙값은 B1 579 / B2 361 / B3 827사이클이었다. 100사이클 이후 경로를 7점 중앙값으로 평활한 후 두 직선을 적합하고, SSE 20% 이상 감소·후반 기울기 1.5배 이상 증가 조건으로 탐색했다. 물리적 knee의 정답이 아니며 예측 시점 이후 정보를 사용하므로 입력에서 제외한다.

B2 39셀 모두 초기 구간 내부에 약 65.35시간의 측정 간격이 있었다. `t`의 인접 기록 차이로 재확인했으며, 실제 휴지·측정 누락·실험 조치 중 무엇인지 확정하지 않았다. 공백이 예측 오류를 일으켰다는 인과 주장도 하지 않는다.

### Q3. ΔQ(V)와 피처 요약

`ΔQ(V) = Q100(V) − Q10(V)`를 1,000개 전압점에서 계산한다. 전처리에서 `summary.cycle`과 배열 인덱스 9·99를 대조하며, 원본 `Vdlin`은 3.5→2.0V이다. 이전 노트북의 3.6V 표기를 고쳤다. 피처 값은 그대로이고 그래프의 전압축 표기만 바로잡았다.

수명 하위 1/3에서 전압별 변화가 더 크다. `log10 var(ΔQ)`와 총 수명의 Spearman 상관은 B1 −0.871 / B2 −0.709 / B3 −0.797로, 배치 간 방향이 같았다. 이것이 인과관계나 배치 간 동일한 회귀식을 뜻하지는 않는다.

### Q4. 충전 조건·실제 전류 패턴

B1 종료 근접 36셀의 명목 평균 C-rate와 수명은 ρ=−0.435였다. 같은 4.8C(80%)-4.8C 정책도 실험집단·배치에 따라 평균 수명이 약 484–1,564사이클로 달라 정책만으로 배치 차이를 설명하기 어려웠다.

cycle 10의 첫 방전 전까지 양의 전류가 흐르는 시간 중 **저장 전류 > 4.2**인 비율을 진단했다. 1분 이상의 기록 간격은 제외했다. 이 고전류 비율과 수명의 상관은 B1 −0.29 / B2 +0.05 / B3 +0.40, 후반 용량 감소 속도와의 상관은 −0.07 / −0.21 / −0.24였다. 관계가 배치에 따라 달라 모델 입력에서 보류했다. 실제 전류 패턴 그림은 [EDA 노트북](../notebooks/01_EDA.ipynb)에 있다.

원정책은 `C1`, `C2`, `SOC1`을 사용하고, 파생정책은 명목 평균 `mean_C`와 최대 `max_C`를 사용한다. `s = min(SOC1/100, 0.8)`일 때 `mean_C = 0.8 / [s/C1 + (0.8−s)/C2]`다.

### Q5. 중복·정책 내부 관계

B1 종료 근접 셀에서 ΔQ 분산·평균·최솟값 간 |ρ|는 약 0.966–0.988이다. 평균·최솟값을 함께 넣지 않고 분산 하나로 시작했다. 분산 입력의 왜도는 +1.11 → 로그 후 +0.22, 수명 자체의 왜도는 +0.30이었다. 입력 변환과 타깃 변환을 따로 비교했다.

`C1`과 `SOC1`의 ρ는 −0.878로 강하게 연결돼 있었다. 정책 평균을 제거하면 ΔQ–수명의 ρ가 약 −0.83 → −0.12로 약해졌다. 이에 정책 단독·ΔQ 단독·결합 입력을 비교해 추가 예측 정보를 확인했다. 정책 내부 표본도 작으므로 이 값만으로 ΔQ가 무용하다고 결론 내리지는 않는다.

## 전략의 구현과 모델 선택

B1 종료 근접 36셀을 정책 그룹으로 분리한다(seed 20261001). 학습 28셀은 16정책, 홀드아웃 8셀은 4정책으로 서로 겹치지 않는다. 학습 28셀 안의 **외부 정책 그룹 4-fold CV**에서 후보를 비교한다. 각 외부 학습 부분집합의 **내부 정책 그룹 3-fold CV**에서 alpha·l1_ratio를 선택한다.

대치·표준화·회귀를 Pipeline에 묶어 내부·외부 학습 폴드에서만 적합한다. 로그 타깃 모델도 원 단위로 복원한 MAPE로 선택한다. 후보 선택은 B1 학습셀 안에서 끝내며, 고정 모델을 홀드아웃·B2·B3에 같은 학습 28셀 조건으로 적용한다. B2 평가 전에 B1 전체로 재학습하지 않는다.

단, 과제 Day 1 요구에 따라 B2·B3의 레이블을 포함한 EDA를 먼저 수행했다. 따라서 엄격하게 봉인된 블라인드 테스트는 아니다. B2·B3 성능을 이용해 후보·하이퍼파라미터를 선택하는 코드는 없으며, 이 탐색 범위를 공개한다.

## 논문 성능과의 비교

과제의 지정 기준 9.1%에 대해 B2는 **27.87 − 9.1 = +18.77%p**다. 이 값은 과제 기준과의 차이로 보고한다.

[원논문](https://web.mit.edu/braatzgroup/Severson_NatureEnergy_2019.pdf)의 초록은 9.1%를 대표 수치로 제시한다. 본문은 모델·테스트셋·이상 셀 제외 여부별 성능을 따로 보고한다.

배치 명칭도 구분해야 한다. 과제는 `2018-02-20` 파일을 B2로 지정했지만, 원논문 Methods는 `2017-05-12`, `2017-06-30`, `2018-04-12` 배치를 기술한다. 이 프로젝트는 **과제 지정 파일**을 그대로 사용하며, 과제 B2를 원논문의 배치나 1차 테스트셋과 동일한 집합으로 간주하지 않는다.

| 비교 조건 | 원논문 | 이 프로젝트 |
|---|---|---|
| 학습 | 41셀 · 개발 데이터에서 분할 | B1 종료 근접 28셀 |
| 배치 파일 | Methods: 2017-05-12 / 2017-06-30 / 2018-04-12 | 과제: 2017-05-12 / 2018-02-20 / 2018-04-12 |
| 1차 평가 | 43셀 · 수명 범위를 포괄한 분할 | B2 39셀 · 배치 전체 |
| 2차 평가 | 모델 개발 이후 생성한 40셀 | B3 레이블 보유 44셀 |
| 입력·모델 | variance / discharge / full 구성 | ΔQ 단일 입력 Ridge |
| 제외 기준 | 측정 잡음·센서 문제 등을 반영 | B1 종료 근접 필터 · B2/B3 레이블 보유 셀 유지 |

논문 Table 1의 단일 분산 모델은 1차 테스트 14.7%(이상 셀 제외 13.2%), 2차 테스트 11.4%다. 같은 입력에 가까운 참고치지만 학습·평가 셀이 달라 직접 성능 우열로 해석할 수 없다. 논문 초록 9.1%를 특정 B2 단일 분산 모델의 수치로 부르지 않는다.

B3의 12.11%와 B2의 27.87% 차이에도 수명 분포·실험집단·표본 구성 차이가 함께 반영된다. B3가 더 좋다는 결과로 특정 배치 요인이 해결됐다고 결론 내리지 않는다.

같은 6C(60%)-3C 정책에서 B1 2셀 평균 수명은 744, B2 standard 2셀은 400사이클이었다. ΔQ 변화의 방향은 수명과 연결되지만 B1에서 배운 관계로 크기를 충분히 설명하지 못했다. 표본 수가 작고 로트·환경 변수가 없으므로 원인을 확정하지 않는다.

검증할 개선 방향은 다중 로트 학습 후 로트별 독립 평가, 새 로트의 소수 레이블을 이용한 보정, ΔQ 기준 사이클의 사전 검증, 과대 예측을 억제하는 분위수·예측 구간의 검증이다. 현재 실행에서 이 개선들이 효과를 냈다고 주장하지 않는다.

## ESS 활용 범위와 한계

실험실 조건에서 예상 수명 순위를 참고해 셀 선별·팩 구성·점검 우선순위를 정하는 보조 지표로 검토할 수 있다. 총 수명 예측이며, 현재 시점의 잔여 수명이나 달력상 교체 날짜를 직접 예측한 것은 아니다.

B2의 과대 예측은 교체 지연과 설비 중단 위험으로 이어질 수 있다. 초기 100사이클로도 긴 수명을 짧게 예측하는 사례가 있어 수명 범위 양쪽의 오류를 모두 관리해야 한다. CV·홀드아웃의 작은 오차를 실제 ESS 운영 성능으로 옮겨 해석할 수 없다.

실제 ESS는 충방전 깊이·휴지·온도·캘린더 열화가 실험실과 다르고, 동일한 Q10·Q100 진단 곡선을 얻기 어렵다. 여러 생산 로트·운영 조건에서의 독립 검증, 표준 측정 절차, 로트 보정, 불확실성과 의사결정 비용의 검증이 추가로 필요하다.
